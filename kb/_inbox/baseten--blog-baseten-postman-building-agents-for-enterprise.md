## The Agent Stack

If you do not control your agents, your agents control your company.

Postman’s [Agent Stack](https://postman.ai/#stack) helps enterprises prepare APIs for agents, control which systems agents can access, and govern their actions. It includes four products.

**Passport:** Secures API access for humans and agents using scoped credential references, without exposing the underlying API keys.

**Fabric:** Acts as an AI-native gateway that routes and governs AI, MCP, and API traffic.

**Astropods:** Serves as an operating system with runtime, observability, and guardrails for your AI agents in production.

**Fern:** Generates documentation, SDKs, and CLIs that make APIs discoverable, typed, and callable by developers and AI agents.

While Postman gives you the tools to build and operate agents, Baseten provides the performant, cost-efficient infrastructure they run on.

## Post-train models for better response quality

For the majority of economically valuable tasks, the gap between what a general-purpose model can do via prompting and what a specialized model can do via post-training is large.

Post-training also improves your agent’s response quality, while enabling you to use a faster, cheaper model. Here’s how it works with Baseten:

- **Train for specific tasks.** Adapt models to the agent’s workflow with supervised fine-tuning and reinforcement learning.
- **Deploy and iterate.** Deploy trained models on Baseten and leverage usage data to guide further training.
- **Work with experts.** Receive direct support from Baseten’s post-training team.
- **Keep ownership.** Retain your model weights, evaluations, and training scripts.
