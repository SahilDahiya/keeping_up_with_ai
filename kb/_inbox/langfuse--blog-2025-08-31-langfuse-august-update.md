# Langfuse August Update

Langfuse August Update: New Observation Types, End-to-End Walkthrough Videos, Agent Demo Project, and more.

![Picture Marc Klingen](https://langfuse.com/_next/image?url=%2Fimages%2Fpeople%2Fmarcklingen.jpg&w=96&q=75) Marc Klingen

Marc KlingenThis month, we've shipped updates to improve tracing for complex agents, enhance team collaboration, and expanded the integration library. Here's what's new:

[New Observation Types](https://langfuse.com#new-observation-types)

![observation types](https://langfuse.com/_next/image?url=%2Fimages%2Fblog%2F2025-08-31-langfuse-august-update%2Fobservation-types.png&w=3840&q=75)


We've introduced new observation types to give you deeper insight into your agent's behavior. You can now semantically label spans as **Agent, Tool, Chain, Retriever, Embedding, and Guardrail**, making it easier to debug and analyze complex traces.

For most agent framework integrations, these types are detected automatically. You can also set them manually via the Langfuse Tracing SDKs.

[End-to-End Walkthrough Videos](https://langfuse.com#end-to-end-walkthrough-videos)

![demo video](https://langfuse.com/_next/image?url=%2Fimages%2Fblog%2F2025-08-31-langfuse-august-update%2Fdemo-video.png&w=3840&q=75)


We've released many new capabilities over recent months. We recorded four new short videos covering observability, prompt management, and evaluation to help you get up to speed quickly.

[Agent Example Project](https://langfuse.com#agent-example-project)

![example project](https://langfuse.com/_next/image?url=%2Fimages%2Fblog%2F2025-08-31-langfuse-august-update%2Fdemo-project.png&w=3840&q=75)


Experiment with our revamped interactive example project (langfuse.com/demo) that uses the Langfuse Docs MCP server to help with Langfuse questions. This example uses the new observation types mentioned above.
