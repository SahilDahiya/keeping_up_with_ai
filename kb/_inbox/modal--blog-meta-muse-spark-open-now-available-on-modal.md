# Muse Spark Open is now available on Modal | Modal Blog

Meta just released weights for Muse Spark Open, and it’s now available on Modal Auto Endpoints.

Muse Spark Open is built for agentic coding and long-horizon tasks, with native multimodal understanding and a 1M-token context window. It supports writing and debugging code, multi-step planning, sequential tool use, and failure recovery across extended workflows.

In Meta’s evaluations, Muse Spark Open scores 76.4 on Terminal-Bench 2.1 using the Terminus 2 agent and 60 on DeepSWE 1.1 using Meta’s preferred harness, with xhigh reasoning effort. See the [released model card](https://huggingface.co/meta-models/Muse-Spark-Open-816B-A42B#benchmarks) for the benchmark results and evaluation settings.

Muse Spark Open runs on Modal as a [Shared Endpoint](https://modal.com/endpoints?model=meta-models%2FMuse-Spark-Open-816B-A42B&type=shared) with per-token billing.
